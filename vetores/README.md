# Exercícios 05 - Vetores e POO
Exercícios práticos de Java focados em *vetores/arrays* e introdução à *Programação Orientada a Objetos (POO)*.
---
### 🧠 Conceitos praticados

- Laço for
- Lógica condicional aplicada a vetores
- Introdução a classes, atributos, construtores e métodos (POO)
- Encapsulamento com getters e setters
- Método toString()
