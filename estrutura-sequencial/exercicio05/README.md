Fazer um programa para ler o código de uma peça 1, o número de peças 1, o valor unitário de cada peça 1, o
código de uma peça 2, o número de peças 2 e o valor unitário de cada peça 2. Calcule e mostre o valor a ser pago.
<br></br>
Obs.: na minha interpretração do exercício proposto, o "código da peça" não teve utilidade nenhuma, sendo que o que está pedindo na saída de dados é somente o valor total a ser pago, precisando calcular apenas a quantidade de peças e o valor unitário respectivamente, totalizando o valor a ser pago.
