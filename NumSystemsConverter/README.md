# ConverterNumSystems 🔢

Conversor de sistemas de numeração desenvolvido em Java como prática de lógica de programação e Programação Orientada a Objetos (POO).

## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos na disciplina de **Arquitetura de Computadores** do curso de **Análise e Desenvolvimento de Sistemas**. O objetivo foi colocar em prática os conceitos de sistemas de numeração aprendidos em aula, implementando as conversões na linguagem Java.

## 🔄 Conversões suportadas

- Decimal → Binário
- Decimal → Hexadecimal
- Binário → Decimal
- Binário → Hexadecimal
- Hexadecimal → Decimal
- Hexadecimal → Binário

## 🏗️ Estrutura do projeto

```
ConverterNumSystems/
├── Main.java        # Interface interativa com o usuário
└── Converter.java   # Classe com os 6 métodos de conversão
```

## 💡 Exemplo de uso

```
CONVERSOR BÁSICO DE SISTEMAS DE NUMERAÇÃO
--------------------------------------------------
1. decimal
2. hexadecimal
3. binário
--------------------------------------------------

Escolha o sistema de numeração que quer converter: 1
Digite o número: 45

--------------------------------------------------
2. hexadecimal
3. binário
--------------------------------------------------

Quer converter para qual sistema de numeração? 3

Resultado: 101101
```

## 🧠 O que aprendi

- Sistemas de numeração: decimal, binário e hexadecimal;
- Como funciona a conversão entre bases matemáticas;
- Aplicação de POO com separação de responsabilidades entre classes;
- Uso dos métodos `Integer.parseInt()` e `Integer.toString()` do Java;
- Estruturas de controle: `switch` e `if/else`
