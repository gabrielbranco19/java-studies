# ConverterNumSystems 🔢

A number system converter built in Java as a practice project for programming logic and Object-Oriented Programming (OOP).

## 📚 About the project

This project was developed as part of my studies in the **Computer Architecture** course in my **Systems Analysis and Development** program. The goal was to put into practice the number system concepts learned in class by implementing the conversions in Java.

## 🔄 Supported conversions

- Decimal → Binary
- Decimal → Hexadecimal
- Binary → Decimal
- Binary → Hexadecimal
- Hexadecimal → Decimal
- Hexadecimal → Binary

## 🏗️ Project structure

```
ConverterNumSystems/
├── Main.java        # Interactive user interface
└── Converter.java   # Class with the 6 conversion methods
```

## 💡 Usage example

```
BASIC NUMBER SYSTEM CONVERTER
--------------------------------------------------
1. decimal
2. hexadecimal
3. binary
--------------------------------------------------

Choose the number system to convert from: 1
Enter the number: 45

--------------------------------------------------
2. hexadecimal
3. binary
--------------------------------------------------

Convert to which number system? 3

Result: 101101
```

## 🧠 What I learned

- Number systems: decimal, binary and hexadecimal;
- How base conversion algorithms work;
- Applying OOP with separation of responsibilities between classes;
- Using Java's native `Integer.parseInt()` and `Integer.toString()` methods;
- Control structures: `switch`, `if/else`.
